# AI Payment Insights Assistant

A beginner-friendly prototype for the PayPal AI Hackathon. It combines:
- PayPal REST API **Sandbox** order creation and capture
- Transaction summaries and category charts
- A scikit-learn Isolation Forest model that flags unusual transaction amounts
- A Streamlit dashboard

> Safety note: this is a learning prototype, not a fraud detector or financial advice tool. Use only synthetic/anonymized data and PayPal sandbox credentials.

## 1. Requirements
- Python 3.10 or newer
- Internet connection for package installation and PayPal Sandbox API calls
- PayPal Developer account with Sandbox REST API app credentials

## 2. Run locally (Windows)
Open the project folder in VS Code, then open Terminal and run:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

If PowerShell blocks activation, use Command Prompt:
```bat
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
streamlit run app.py
```

Streamlit will print a local URL, usually `http://localhost:8501`.

## 3. Set up PayPal Sandbox
1. Open https://developer.paypal.com/
2. Sign in and open **Apps & Credentials**.
3. Select **Sandbox** and create or select a REST API app.
4. Copy the Sandbox Client ID and Secret.
5. Run the app, then paste those sandbox credentials into the sidebar.
6. In the PayPal Sandbox tab, connect, create a test order, open the approval link, approve using a sandbox buyer account, and capture the order.
7. Do not use live credentials. Do not commit credentials or `.env` to GitHub.

You may alternatively copy `.env.example` to `.env` and fill in sandbox credentials there. Keep `.env` private.

## 4. Upload transaction CSV
The required column is `amount`. Optional columns: `date`, `category`, `description`.

Example:
```csv
date,amount,category,description
2026-10-01,250,Food,Lunch
2026-10-02,1800,Shopping,Shoes
```

The app starts with synthetic sample data if no CSV is uploaded.

## 5. Current limitations and honest disclosure
- The anomaly detector uses transaction amount only; flags require human review and do not establish fraud.
- The text review reasons are rule-based, not generated by a large language model.
- PayPal integration uses the Sandbox REST API, not real payments.
- This initial version does not import a user's PayPal transaction history.
- Do not claim generative AI integration unless you add and test an actual AI model/service and disclose its use.
